# 第六章 · 教学 Agent

面向《土木工程结构工程设计原理》第六章的引导式学习应用，涵盖钢筋混凝土梁的受弯、受剪与相关知识。

应用源码和运行说明位于 [teaching-agent](teaching-agent/README.md)。使用 Next.js、React、TypeScript，以及现有 shadcn/Radix、Lucide 和 Motion 组件。

## 功能

| 板块 | 内容 |
| --- | --- |
| 引导对话 | 按学生作答追问，支持题目卡片、公式、图片与笔记 |
| 自学天地 | 148页课件、知识点、要点与扩展练习 |
| 题库自测 | 题量/题型/难度设置、交卷反馈、错题本与导出 |
| 实时课堂 | 教师建课和发题，学生扫码加入，实时答题分布 |
| 资料下载 | 课件与学习资料整理 |
| 新增：关联练习 | 单筋/双筋主题、关联补练、返回原题与独立学习记录 |
| 新增：单筋与双筋 | 适筋/少筋/超筋、双筋受压筋状态，支持播放、阶段定位及截面应变 |

界面统一采用选定的 Kimi Web 设计规范，保留东南大学课程品牌。两个新增功能集中在侧栏“新增功能”，记录独立保存。

## 新功能与验证

- [关联练习说明](teaching-agent/docs/linked-practice/README.md)：610条结构完整题目、22条已定位关联。结构完整不代表专业答案已全部复核；判断/选择按资料参考答案核对，填空/计算采用自评。
- [演示动画说明](teaching-agent/docs/beam-demo/README.md)：五种情形、两种视图；动画为定性教学示意，图形参数不用于实际工程设计计算。

**本次修复**

1. 修正 `/self-test`、`/classroom` 的重定向，避免 Next.js 与业务代码重复添加 `/teachdemo`，导致独立入口 404。
2. 修正笔记打印窗口的事件注册顺序。`document.open()` 会清除已有监听，原实现因此未自动触发打印；现已验证真实窗口加载图片并调用打印。
3. 修正 Select 菜单层级，确保错题导出弹窗中的模板、范围等菜单可以点击。
4. 增加首轮教学约束：首轮不提前判题或发卡片；漏发资料时按已有章节索引补课件，教材节不编造 PPT，模型报错时不伪装为成功。
5. 增加课程事实约束，明确 T 形分类比较翼缘厚度、缺失材料等级时不擅自代入数值、没有学生作答时不称其答对。真实模型验收增加翼缘宽度与厚度误用的检查。

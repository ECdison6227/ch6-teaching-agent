## 统一规则与差异

继续原样使用来源主题变量、系统字体栈与已接入的源 SVG。沿用 shadcn/Radix、Lucide、Motion，未增加 npm 依赖。正文列在 Kimi 的 720/768/800px 角色基础上适配：课程、资源、自测、课堂统一为 800px 有效内容（864px 外列含两侧 32px 内距），顶栏统一 52px，页面标题统一 22/36/500，正文题干 16/28，辅助文案 12/20、14/24。主卡 20px 圆角，选项 12px，控件反馈 150ms，减少动画分支继续生效。

上述页面组合、测验状态、分布统计和流程是 D 目标适配，不声称 Kimi 存在相同的教学功能。课程内容、课件图像与原品牌保持原样，因此课件自身的色彩不改成黑白；对话继续使用来源的居中 768px 输入构图。

## 本轮实测

- 五个工程生产构建通过，构建包含类型检查；三份有自测/课堂功能的工程在最终流程调整后再次构建通过。
- 现有回归：22 + 22 + 52 + 42 + 42 = **180 项通过**。原始日志和结果见 `validation.json` 与 `validation.json`。
- CUA / Windows Chrome 真实操作：设置修改/取消与焦点返回；5 道判断题作答、跳题、切板块、刷新恢复、未答确认与结果；原错题保留；错题直接重练、重复错误按题目合并并累计至 2 次。
- 真实课堂数据库操作：发布第 2 题 TF-02；学生选 T 后在未提交时刷新恢复草稿；提交 T、改为 F 并更新；教师统计显示已答 1/1、未答 0；收题后选项禁用；公布后学生显示标准答案 T 与解析。旧 TF-01 轮次和参与者保留。
- /self-test、/classroom 已分别实际跳转到 /#self-test、/#classroom。五个 43410–43414 服务健康检查 200。
- 结果页「再练一次」实测仍是 TF-08 的 1 题快照；答 F 后得到 100%，原错题本仍保留 1 题。
- 已更新原有 platform-smoke、classroom-browser-check 和样式验证脚本的页面操作路径；本轮没有另启 Playwright 绕过 CUA 运行这些 GUI 脚本，不能把脚本更新称为平台验收通过。

## 截图与验证边界

`before/` 为本轮改造前真实截图，`after/` 为新版实际截图。主要目标截图为当前 Chrome 约 2195×1066 CSS px；与本轮改造前是同一浏览器条件，题量/轮次随测试变化，比较页面构图和操作层级。学生页另有实际 390×844 CSS px 窄屏截图，已核对 20px 标题、16px 内距与约 367px 内容列。来源项目图为 1455×878/DPR1.75，匿名来源为 1440×1000/DPR1；来源对照为布局角色与尺寸映射，不冒充同画布逐像素比较。图片与状态分次采集，不是原子快照。

本轮主预览的 viewport 能力调用没有改变实际 innerWidth；新建测试页亦未改变。尝试的 390px 同源 iframe 没有产生可验收内容，临时测试页已删除。随后核实已有学生页的真实视口为 390×844，其窄屏版式已截图检查。因此**只确认学生页窄屏；自测/教师端窄屏、真实移动 OS/软键盘本轮未验收**，不继承上一轮窄屏通过数作为本轮通过结果。新 CSS 提供 568px 以下布局，待所需 Android、macOS、Windows 平台检查实际执行后再合入。

本轮导出弹层的范围、模板和题量可用，模板/导出数据回归通过；CUA 下载事件等待未取得可确认的文件路径，因此未把实际下载落盘列为通过。没有移除或改写原导出实现。

当前用户 Chrome 的翻译扩展给 html 注入 `data-immersive-translate-page-theme`，React 开发模式对此报告 hydration 属性差异。本轮保留了警告，没有用 suppressHydrationWarning 隐藏；实际交互和构建已完成。AI 预览无可用模型，本轮不使用真实付费模型。

原版真实故障/取消、移动 OS、完整读屏与逐帧动效的研究边界继续保留。180 项回归或来源完整性检查不等于上述真实平台全部通过。

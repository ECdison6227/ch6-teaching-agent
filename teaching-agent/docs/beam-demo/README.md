# 单筋与双筋演示

独立入口：侧栏“新增功能 → 单筋与双筋”，直接访问 `/reinforcement-demo`。与关联练习共用原有工作区、组件和 Kimi Web 样式。

## 本次交付

- 单筋：适筋、少筋、超筋；分别展示屈服与破坏的先后。
- 双筋：受压筋充分发挥、受压筋未屈服；不把“配置了受压筋”当作“受压筋必然屈服”。
- 梁变形、截面应变两种视图；连续播放、暂停、重播、进度拖动、四阶段定位。
- 暂停、切换视图、离开页面和页面隐藏时停止播放并保存检查点；返回或刷新后恢复工况、视图和进度。
- 切换工况重置进度并停止旧动画，代次校验防止旧帧回写；播放中重播会新建播放轮次。
- 遵循系统减弱动态设置，关闭自动播放，仍可逐阶段和拖动查看。
- 记录使用独立 key `ch6-beam-demo-v1`。读取失败不覆盖原记录，写入失败保留内存并提供重试。

## D 选择与流程调整

旧 ReinforcementLab 是配筋率静态示意，没有双筋连续播放；保留其原教学上下文，新增独立的可播放页面。Kimi 包无本领域动画资产，故 SVG 只承担业务图形；所有控件仍为既有组件。

用户先选单筋/双筋，再选情形，默认直接播放或点击阶段。复杂说明收起；状态用短句，受拉/受压筋屈服以现有蓝色强调，裂缝/压区破坏使用既有 destructive 色。手机图中文字加大，阶段按钮两列显示。

图形形变、裂缝宽度、中和轴轨迹、8/10/12秒时长及阶段占比全部为 D 教学示意。进度不代表荷载、真实时间或承载力。只显示参与受弯的纵筋，省略架立筋与箍筋。少筋开裂和快速失效刻意相接并放慢展示；该情形不画成受压混凝土先压碎。点击开裂阶段即出现初始裂缝。

李坤模型、权重文件、截面参数求解和设计计算仍按用户要求暂缓；此功能不代替工程设计验算。

# 功能：题库随机自测、难度筛选与错题预设导出

## 目标与使用流程

学生进入「题库自测」，设置题量、题型和难度，从已有题库随机生成一份不重复的试卷；完成后统一交卷、查看结果与解析。确定答错的题自动进入独立错题本，支持重练、移出，以及按预设模板导出。

关联任务：https://github.com/ECdison6227/ch6-teaching-agent/issues/2。本 issue 由线程 A 负责，是完整的自测功能，不按前端、后端分工。

评估基于当前 `main` 的 `ad34fcf`。建议使用独立分支 / 工作树 `feat/self-test-wrongbook`，不要与线程 B 在同一工作目录并发切分支、提交或改依赖。

## 已核实的项目基础

- 项目为 Next.js 15 App Router / React 19，应用目录是 `teaching-agent/`。
- `src/lib/questions.ts` 合并两个 JSON 题库，共 150 题：选择 93、判断 49、填空 8。其中 `verified === true` 的有 115 题：选择 66、判断 46、填空 3；未复核 35 题，其中 1 题没有答案。
- 全部题目目前都没有难度字段。`confidence` 是答案置信信息，不能用于表示难度。
- 已有 `grade()`、Markdown / KaTeX 和练习作答界面；已有 `pickQuestions()` 按章节匹配并取前几题，不是随机组卷，不能直接当随机抽题使用。
- 已有笔记存储、打印导出能力，但没有独立错题本；笔记最多保存 80 条，错题不可存进笔记集合充当持久化。
- 当前导航由 `AppShell.tsx` / `Sidebar.tsx` 的页内状态控制。共用导航的最终接入由线程 B 统一完成。

## 首版产品规则

### 1. 组卷设置

| 设置 | 首版规则 |
| --- | --- |
| 题量 | 5 / 10 / 20 / 30 题快捷选项；支持自定义正整数，默认 10 题 |
| 题型 | 选择题 / 判断题 / 填空题，可多选，默认全部 |
| 难度 | 简单 / 中等 / 困难，可多选，默认不限 |
| 可用题 | 仅抽取已复核、有标准答案且结构有效的题；选择题须有有效选项 |
| 数量提示 | 设置变化时显示符合条件的可用题数；0 题时显示原因并禁止开始 |
| 题量不足 | 明确提示“当前条件仅有 N 题”，允许用户一键改为 N 题；不得暗中补入其他难度、题型或未复核题 |
| 随机性 | 先过滤，再使用 Fisher–Yates 等无偏洗牌进行无放回抽样；同一份试卷不能重复 |

筛选语义：同一维度内取并集，不同维度间取交集。首版不做题型比例配额；再次组卷允许遇到上一次的题，不承诺跨场次去重。

### 2. 难度标注必须真实落地

用独立的 `src/content/question-meta.json` 按题目 ID 保存元数据，不改动原题干、答案、`verified` 或题目 ID。为全部 150 题补齐初始难度，至少确保 115 道可抽题全部覆盖，并在说明中给出标注口径与各级数量：

- 简单：直接考察一个概念、事实或判断，不需要串联多个条件。
- 中等：需要区分相近概念，或完成一步条件判断、公式应用。
- 困难：需要组合多个条件、比较适用边界，或进行多步推理。

不得按题型一刀切、按 ID 取模、随机生成难度，或把答案置信度当难度。保留逐题调整的入口为数据文件即可，首版不新增题库管理后台。

### 3. 自测与结果

- 流程为「设置 → 作答 → 交卷 → 结果 / 错题」。支持上一题、下一题、修改作答、查看已答进度与定位未答题。
- 交卷前不显示标准答案和解析；存在未答题时用已有 Dialog 明确提醒，再允许交卷。
- 使用现有 `grade(question, answer)`；`true / false / null` 分别对应答对、答错、待核对。空白答案单独标为未作答，不归到待核对或错题。
- 结果显示总题数、答对、答错、待核对、未答、完成率；正确率按 `答对 /（答对 + 答错）` 计算，分母为 0 时显示「暂无可判定结果」。同时显示完成率，避免隐藏未答题。
- 结果页逐题展示我的答案、标准答案和解析；无解析时如实提示。填空题仍沿用现有等价写法、空位顺序、数值与单位判定，不用 AI 自动判题代替现有规则。
- 重复点击交卷只生成一次结果、一次错题更新；网络模型不可用不影响组卷、交卷和导出。
- 本次题目顺序、题目快照、已填答案及结果需要在本设备持久化；刷新后可继续未完成的自测或查看最近结果，不因重新渲染再次抽题。

### 4. 独立错题本

- 只有 `grade() === false` 的题自动进入错题本；待核对、未答题不自动记错。
- 按 `questionId` 合并同题，保存题目快照、最近错误答案、标准答案、解析、累计答错次数和最近答错时间；同一场的重复提交不得重复累计。
- 支持浏览、勾选、按题型 / 难度筛选、错题重练和手动移出。重练答对后保留原记录，交由用户决定是否移出。
- 题库更新后仍能查看和导出旧错题快照；若要按最新题目重练，需明确使用哪一版本，不能悄悄覆盖旧作答依据。
- 新建独立的浏览器存储模块与 key / object store。可复用 `notes-store.ts` 的持久化设计，不能占用或覆盖现有笔记数据。
- 保存失败时保留当前内存数据，显示未保存状态并支持重试；读取失败不能拿空集合覆盖旧数据。不静默截断为 80 条，不假定已有登录或跨设备同步。

### 5. 错题导出：给出三个可直接选用的模板

导出前选择范围：本次自测错题 / 全部错题 / 当前勾选；可选最近 10 题 / 最近 20 题 / 全部，按最近答错时间倒序取题。范围为空时禁用导出并解释原因。

| 模板 | 内容 | 用途 |
| --- | --- | --- |
| 对照纠错（默认） | 题干、选项、我的错误答案、标准答案、解析 | 逐题找错因 |
| 空白重练 | 题干、选项、作答留白；默认不含答案和解析 | 打印后重新做题 |
| 简洁复习 | 题干、选项、标准答案、解析；不含个人作答 | 集中回顾 |

- 首版提供浏览器打印 / 另存为 PDF 和 Markdown 文件下载；界面如实标明打印方式，不伪装成直接生成的 PDF 文件。
- 导出内容来自所选错题快照，不调用 `/api/digest` 或 AI 改写答案。
- 复用 Markdown / KaTeX 渲染及已有打印机制，处理弹窗拦截、字体和图片加载、分页、长公式溢出。空白重练的可见内容和导出数据均不得混入答案。
- 文件名包含日期、模板名和题数。正文包含导出范围及导出日期；0 条记录不能导出空白文件。

## 实现建议与共用契约

路径均相对于 `teaching-agent/`；可按实现小幅调整，但共用契约变更需要同步关联 issue。

```ts
// src/lib/question-catalog.ts，由线程 A 所有
import type { Question } from "./questions";

export type QuestionDifficulty = "easy" | "medium" | "hard";
export type CatalogQuestion = Question & { difficulty: QuestionDifficulty };

// 参数显式传入，便于课堂服务端和自测复用，不引入浏览器依赖。
export declare function getQuestionCatalog(): readonly CatalogQuestion[];
export declare function isUsableQuestion(question: Question): boolean;
// isUsableQuestion 至少检查 verified === true、答案与题型结构。
```

共用模块只能包含题库、类型及纯函数，不引用 React、浏览器存储或 Node 文件写入。课堂线程可以在服务端读取完整题库，但不得把 `CatalogQuestion` 原样作为学生接口响应。

上例为签名约定，实施时需要提供函数体。`isUsableQuestion` 不因缺少难度而改变判定，难度覆盖由 catalog 的元数据校验保证。
